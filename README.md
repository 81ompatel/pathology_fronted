# Pathology Frontend Module

An Angular 17 Single Page Application for Pathology Management.

## Tech Stack
- **Framework:** Angular 17 (Standalone Components)
- **Language:** TypeScript
- **Styling:** Custom CSS (Glassmorphism design)
- **State/Routing:** RxJS, Angular Router, Reactive Forms

## Setup Instructions

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (which includes `npm`).

### 1. Installation
Open a terminal in this directory and install all required Node modules:
```bash
npm install
```

### 2. Running the Development Server
Start the Angular server by running:
```bash
npx ng serve
```

### 3. Usage
- Open your browser and navigate to `http://localhost:4200`.
- **Note:** Ensure that the Spring Boot backend server is also running on `http://localhost:8081` so that the frontend can successfully fetch and save data.
